# Changelog

## 1.0.2 (2026-11-25)

### Features

- Graphs and tables can be imported into Grafana directly from XorMon (adding a graph or table to a Grafana dashboard, or syncing XorMon dashboards). The Infinity plugin is no longer needed.
- New **XorMon URL** query type for imported graphs, capacity tables and alerting tables. The panel is linked to its XorMon page and tab, so it follows changes of the source graph (new items, metrics) and keeps the XorMon styling of the metrics.
